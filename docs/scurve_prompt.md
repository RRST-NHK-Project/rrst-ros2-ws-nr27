## §1 ゴール

速度と加速度に加えて、**ジャーク（加速度の変化率）にも上限を付けた S 字の速度プロファイル**を実装し、今の「加速度だけを制限する台形プロファイル」と置き換える。

目的は、ブロック（350 mm 角を 2 個重ねると背が高い）を運ぶときの揺れと、止まった瞬間の振れを減らすこと。代償として加減速が少し遅くなる。その遅れが式どおり `A/J` 秒に収まっていることもテストで確かめる。

作るものは 3 つ。

1. **計画版（1 次元）**：始点と終点が分かっている移動を、事前に S 字で計画する。DOCK モードの寄せや、ステアの参照軌道に使う。
2. **逐次版（1 次元）**：目標速度が毎周期変わる入力を、ジャーク制限を守りながら追う。
3. **逐次版（ベクトル）**：機体速度 `(vx, vy, ω)` に、**速度ベクトルの向きを保ったまま** 2 をかける。今の `stack.py` の加速度制限をこれで置き換える。

1. **まず Python の参照実装（`tools/swerve_stack/`）に入れてテストを通し、その後で C++ に移す。** C++ 版は Python 版と同じ入力に同じ出力を返すことを、テストで確かめる。

   - `float` のみを使う（`double` は使わない）。

   - ヘッダだけで完結させる。
6. **既存のテストを壊さない。** 数値が変わるテストは、理由をコメントに書いて更新する。

## §3 式（これを正とする）

記号：加速度の上限 `A`、ジャークの上限 `J`、立ち上げ時間 `T_j = A / J`。

### 3.1 加速の 1 区間（v₀ → v₁、`Δv = v₁ − v₀ > 0`）

加速度は台形を描き、3 段階に分かれる。

| 段階 | 時間 | ジャーク | 加速度 | 速度 | 位置 |
|---|---|---|---|---|---|
| ① | `0 ≤ t ≤ T_j` | `+J` | `J t` | `v₀ + J t²/2` | `v₀ t + J t³/6` |
| ② | `0 ≤ τ ≤ T_a` | `0` | `A` | `v_① + A τ` | `x_① + v_① τ + A τ²/2` |
| ③ | `0 ≤ τ ≤ T_j` | `−J` | `A − J τ` | `v_② + A τ − J τ²/2` | `x_② + v_② τ + A τ²/2 − J τ³/6` |

`v_①, x_①` などは、前の段階の終わりの値。

**ケース 1：加速度が A に届く場合（`Δv ≥ A²/J`）**

```
T_a = Δv/A − A/J
T   = Δv/A + A/J
D   = (v₀ + v₁)/2 × T
```

**ケース 2：A に届かない場合（`Δv < A²/J`）**

段階②がなくなり、ピーク加速度は `√(J Δv)` になる。

```
T = 2 √(Δv/J)
D = (v₀ + v₁) × √(Δv/J)
```

減速は、符号を反転した同じ形で扱う。

### 3.2 止まった状態から止まるまで（距離 L）

**最高速に届く場合**（`L ≥ 2 × D(0→v_max)`）

途中に等速区間が入る。

```
T = L/v_max + v_max/A + A/J
```

**届かない場合**は、ピーク速度 v_p を次で求める。

ケース 1（`v_p ≥ A²/J`）：

```
v_p = (A/2) × ( −A/J + √( (A/J)² + 4L/A ) )
```

ケース 2：

```
v_p = (J L² / 4)^(1/3)
```

**順番：ケース 1 の式で計算し、得られた v_p が `A²/J` 未満ならケース 2 で計算し直す。**

初速と終速がゼロでない一般の場合（`v₀ ≠ 0` や `v_end ≠ 0`）は、ピーク速度を二分法で求めてよい。

### 3.3 J の決め方

立ち上げ時間 `T_j` を、揺らしたくないものの揺れの周期（またはその整数倍）に合わせると、加減速の切り替わりで揺れが残らない。

```
J = A × f_n          （f_n：揺れの固有振動数 [Hz]）
```

**YAML には `J` か `f_n` のどちらかを書けるようにし、`f_n` が書かれていればそこから `J` を計算する。** モード（格納 / 展開 / ブロック積載）ごとに値を持てるようにする。

### 3.4 逐次版（1 次元）の判定

周期 `dt` ごとに、残りの速度差 `e = v_target − v` と、今の加速度 `a` から次の加速度を決める。

- **e と a が同じ向き**で、`|e| ≤ a²/(2J) + |a|·dt` のとき：`|a|` を `J·dt` だけ 0 に近づける（立ち下げ）。
- **それ以外**：`a` を e の向きへ `J·dt` だけ動かす。ただし `|a| ≤ A` に制限する。
- **`|e|` と `|a|` が両方十分小さい**（`|e| < J·dt²`、`|a| < J·dt`）とき：`v = v_target`、`a = 0` にそろえる（目標付近でのチャタリング防止）。

`a²/(2J)` は、今の加速度を傾き J で 0 まで下げる間に増える速度。`|a|·dt` は離散化で 1 周期判定が遅れる分の余裕。

目標が途中で逆向きに変わる場合（加速中に減速指令が来るなど）も、上の判定で正しく扱えること（§5 のテスト）。

> **追記（2026-11-24 合意）：上の 1・2 つ目の判定を次に置き換える。3 つ目（目標付近でそろえる）はそのまま。**
>
> 毎周期、次の加速度 `x` を、「`x` で 1 周期進み、そのあと J で 0 まで下げたときに増える速度」
> `g(x) = x²/(2J) + |x|·dt/2` が `|e|` にちょうど等しくなる値に選び、ジャークと加速度の上限で切る。
>
> ```
> x* = sign(e) · J · ( −dt/2 + √( dt²/4 + 2|e|/J ) )
> a  = clip( clip(x*, a − J·dt, a + J·dt), −A, A )
> v += a·dt
> ```
>
> 理由：原文の判定は、立ち下げを始めても `a²/(2J)` が e より速く小さくなるので「それ以外」に戻って加速度を上げ直し、
> A = 3、J = 15、0 → 2 m/s で行き過ぎが O(A·dt)（dt = 0.01 s で 0.0055 m/s、基準 J·dt² = 0.0015）、
> 到達が 4〜5 周期遅れ、目標付近で加速度が一度逆向きに振れ、§5 の逐次版のテストに通らなかった。
> 置き換えた式では、行き過ぎが O(J·dt²)（約 0.11·J·dt²）、到達は計画版から 1 周期以内、加速度は振れない。
> `|x|·dt/2` は、`v += a_new·dt` で更新したときの立ち下げ中の離散の和を閉じた式にしたもの。
> 3.5 のベクトル版も、同じ考え方を `ẽ` 方向の成分に当てはめる。
>
> 補足：§5 の「台形との差が時間でちょうど `A/J`」は、ケース 1（`Δv ≥ A²/J`）のときだけ成り立つ。ケース 2 では `A/J` より小さい。

### 3.5 逐次版（ベクトル）

機体速度 `ν = (vx, vy, ω)` に対して、次の手順で行う。

1. **正規化する。** 各軸を、その軸の加速度上限で割った空間で計算する：`ν̃_i = ν_i / A_i`。並進と回転の単位をそろえるため。
2. **加速度ベクトル `ã` を状態として持つ。** 残りの差 `ẽ = ν̃_target − ν̃` に対して、3.4 の判定をベクトルで行う。
   - **立ち下げの判定**：`ã` の `ẽ` 方向の成分を使う。
   - **加速度を増やすとき**：`ã` を `ẽ` 方向の単位ベクトル × 1 に向けて、変化量のノルムを `J_n·dt` で制限する（`J_n = J/A`）。
   - `|ã| ≤ 1` に制限する。
3. **`ν̃ += ã·dt` で更新して、元の単位に戻す。**

**目的：目標の向きが変わらない限り、速度ベクトルの向き（＝ステア角）が加速の途中で変わらないこと。** 目標の向きが変わったときは、加速度ベクトルが J の範囲で回り込む。厳密な時間最適でなくてよいが、向きの保存とジャーク上限は必ず守ること。

## §5 テスト

### 式の検証（1 次元）

- 次の値と一致すること（許容誤差 0.5%）。条件は `A = 3 m/s²`、`J = 15 m/s³`。

| 加速 | ケース | 時間 | 距離 |
|---|---|---|---|
| 0 → 2 m/s | 1 | 0.8667 s | 0.8667 m |
| 1 → 2 m/s | 1 | 0.5333 s | 0.8000 m |
| 0 → 0.4 m/s | 2 | 0.3266 s | 0.0653 m |

- `L = 2 m`、`v_max = 2 m/s` で、所要時間が 1.8667 s であること。
- `v_max` の制限なし・`L = 2 m` でピーク速度が 2.168 m/s であること。
- `L = 0.1 m` でピーク速度が 0.3347 m/s（ケース 2）であること。
- 計画版の出力を細かい刻みで数値積分し、終点の位置・速度・加速度が計画と一致すること。
- 台形との差が、時間でちょうど `A/J`、距離で `(v₀+v₁)/2 × A/J` であること。

### 逐次版

- 速度・加速度・ジャークの上限を、全周期で守ること（離散化の誤差の許容を明記する）。
- 目標速度をステップで与えたとき、行き過ぎ（オーバーシュート）が `J·dt²` 程度以下であること。
- 0 → 2 m/s の到達時間が、計画版の 0.8667 s と、1 周期分の誤差内で一致すること。
- 加速の途中で目標を逆向き（−1 m/s など）に変えても、ジャーク上限を守ったまま新しい目標に着くこと。
- 目標付近で加速度が振動しないこと。

### ベクトル版

- 目標の向きが一定なら、加速中の速度ベクトルの向きが、目標の向きから変わらないこと（角度の差 1e-6 rad 以下）。
- 正規化した空間で、加速度ベクトルの変化のノルムが `J_n·dt` を超えないこと。
- 回転だけ、並進だけ、両方同時の 3 通りで、上の 2 つが成り立つこと。

### シミュレーション比較

`scenarios.py` に「台形」と「S 字」の比較を追加する。3 場面（直進・旋回移動・坂）× シード 3 本で、次を表に出す。

- 位置 RMS
- 所要時間
- 機体の加速度の変化率（ジャーク）の RMS と最大値
- ステア総移動

腕やブロックの揺れはプラントに入っていないので、揺れの代わりに機体ジャークで比べる。プラントに 1 自由度の揺れ（ばね・質量・減衰。`f_n` はパラメータ）を足して、止まった後の残留振動の振幅を比べられるとなお良い。その場合は、`J = A × f_n` にしたときに残留振動が最小になることも確かめる。

### C++

上のテストのうち、式の検証・逐次版・ベクトル版を、C++ でも同じ値で通すこと（ゴールデンテスト）。
